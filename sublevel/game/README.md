# Sublevel (build steps 1 to 4 done; art pass next)

Step 1, the look test, was approved on 2026-11-26 and is still at `/?look`. Step 2, the layout, is a first pass: all 36 rooms, four floors, and a stairwell at each end of the building (the east one was added on 2026-11-26 to shorten work order 4).

Step 3, the work orders, is playable from start to finish with placeholder art:

- A wall phone rings in a room. Answering it (E) gives the work order (captioned) and about three questions on the phone panel. Then the player is sent to find a room: the safe room, where the goat waits on a desk.
- The six work orders go H → Li → Mg → Cl → Fe → As → K. The last one ends at the exit door in the potassium room (the largest atom).
- **The dark.** After each call, the rooms and hallway stretches the player has passed go dark one by one behind them. Wrong answers in that work order make it faster, and so does lingering. If everything behind is dark and the player still lingers (or stands in a dark room), the lights fail around them and they are taken back to the last phone, with no points lost. Reaching the safe room turns every light back on. Lights-on mode turns the dark off.
- **Scoring** (confirmed 2026-11-26): 1 point per work order, 6 in all. Wrong answers never cost points.
- **The donkey** stands across one wrong door for each search. After two wrong answers a question shows a hint; after two minutes of searching the objective shows one. Both stand in for the chicken until there is a chicken model.
- Door plates in the tiled rooms (p block) show the short configuration. Parking bays have the 3d electron count painted on the floor, except chromium and copper (out of scope).
- Debrief ("What the building was telling you") and the completion code (Daughter's scheme, prefix `SL`, confirmed 2026-11-26, registered in the private checker the same day). Changing the secret in `src/config.js` means changing it in the checker too.

Step 4, the question pools, was checked against the Chapter 5 slides (Basic Chemistry 6e, "Electronic Structure of Atoms and Periodic Trends", sections 5.3 to 5.6) and approved by Prof. Picione on 2026-11-26, with the debrief wording:

- Each work order has three question slots, and each slot is a pool of 3 or 4 variants on the same idea, 71 in all. One variant per slot is drawn when the phone is answered, and the answer choices are shuffled (number lists keep their order).
- Configurations are written as on the slides: no spaces between sublevels, the noble gas core in brackets, 4s before 3d (`[Ar]4s²3d⁶`): filling order, the way Prof. Picione teaches it, not numerical order. Correct answers are generated by `src/chem.js`, not typed.
- The terms follow the slides: "Group 5A (15)"; the pairing rule is stated without a name (the slides do not name Hund's rule); the Pauli exclusion principle is named, as on the slides.
- Out of scope, as set in the handoff: atomic spectra and light (5.1, 5.2), ionization energy and metallic character (5.6), and the chromium and copper exceptions. Electron-dot symbols are not in the Chapter 5 slides, so they are left out.

## Run it

```
cd sublevel/game
npm install
npm run dev
```

Then open http://localhost:5181/.

| URL | What it does |
|---|---|
| `/` | Auto: measures the computer and picks a tier (Daughter's speed test) |
| `/?tier=ultra` (or `high`, `medium`, `low`) | Starts on that tier |
| `/?webgl` | Forces the WebGL 2 backend |
| `/?fresh` | Ignores the run saved in this browser |
| `/?look` | The approved step 1 look test |

Keys: WASD move · Shift faster · mouse look (or drag) · E use · Esc pause · **1 Low, 2 Medium, 3 High, 4 Ultra, 0 Auto**.

## Tiers (handoff section 8)

| | Ultra | High | Medium | Low |
|---|---|---|---|---|
| Surfaces | PBR, 2K | PBR, 2K | PBR, 1K | Flat colors (no texture files) |
| Shadows from the tube lights | 1024 | 512 | None | None |
| Grounding | Screen-space GI and AO | Screen-space AO | Texture AO only | None |
| Water | Screen-space reflections, ripples, caustics | Same, half resolution | Environment-map reflection, ripples | Flat tint, still |
| Post | TRAA, bloom, grain, vignette, slight color fringe | TRAA, bloom, grain, vignette | FXAA, bloom, vignette | None |
